# Agent Empty-Session Guide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a calm welcome placeholder that appears in the agent chat area when the current session has zero messages, and fades away once the user sends their first message.

**Architecture:** Non-interactive absolute-positioned overlay rendered as a template sibling of `<pi-chat-panel>` inside `dao-chat-view`, gated by `messageCount_ === 0 && !isStreaming_ && !compacting_`. Styling added to `agent.css` alongside the existing sibling-layout rules. No changes to vendor code, agent state, or build graph.

**Tech Stack:** TypeScript + lit-html, Chromium WebUI (light DOM), project-native CSS variables (`--text-secondary`, `--text-tertiary`).

- Sending the first message hides the overlay immediately; subsequent streaming and compaction never bring it back until the session is empty again.
- Composer input remains fully usable while the overlay is visible.
- `npm run rebuild` succeeds.
- No changes to vendor files, BUILD.gn, browser tests, or agent session/state management.
