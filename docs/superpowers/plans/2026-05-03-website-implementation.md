# Dao Browser Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Dao Browser official landing page at `dao.msgbyte.com` as a Next.js static export living in `website/` of the main repository.

**Architecture:** Next.js 15 App Router with `output: 'export'` for static HTML; React Server Components only (zero client JS beyond Next.js runtime); CSS Modules + globals.css with design tokens mirrored verbatim from the main project's `DESIGN.md`; built artifacts deployed to Cloudflare Pages.

**Tech Stack:** Next.js 15, React 19, TypeScript 5, CSS Modules, Lucide icons (inline SVG, fetched from upstream), zod (lightweight runtime validation of `dao.json`).

**Spec:** `docs/superpowers/specs/2026-05-03-website-design.md`

## Task 2: Implement `lib/version.ts` reading `dao.json`

**Files:**
- Create: `website/lib/version.ts`
- Test: manual via `tsc --noEmit` and a temporary console assertion

This task introduces the single source of truth for product/Chromium version, GitHub URL, site URL, and the macOS download URL. Validation uses zod so a malformed `dao.json` fails the build with a clear error.

- [ ] **Step 1: Create `website/lib/version.ts`**

```ts
import { z } from 'zod';
import daoJson from '../../dao.json' assert { type: 'json' };

const DaoConfigSchema = z.object({
  version: z.object({
    product: z.string(),
    version: z.string(),  // Chromium version, e.g. "147.0.7727.135"
    display: z.string(),  // Product version, e.g. "0.5.0"
  }),
});

const parsed = DaoConfigSchema.safeParse(daoJson);
if (!parsed.success) {
  throw new Error(
    `Invalid dao.json shape: ${parsed.error.message}. ` +
    `lib/version.ts expects version.{product,version,display}.`
  );
}

export const PRODUCT_VERSION = parsed.data.version.display;
export const CHROMIUM_VERSION = parsed.data.version.version;

export const GITHUB_URL = 'https://github.com/moonrailgun/dao-browser';
export const SITE_URL = 'https://dao.msgbyte.com';
export const DOWNLOAD_URL_MAC_ARM64 =
  `${GITHUB_URL}/releases/download/v${PRODUCT_VERSION}/dao-browser-${PRODUCT_VERSION}-mac-arm64.dmg`;
```

```tsx
import type { AnchorHTMLAttributes } from 'react';
import styles from './Button.module.css';

type Variant = 'primary' | 'ghost';

export interface ButtonProps extends AnchorHTMLAttributes<HTMLAnchorElement> {
  variant?: Variant;
  fullWidth?: boolean;
  external?: boolean;
}

export function Button({
  variant = 'primary',
  fullWidth = false,
  external = false,
  className,
  children,
  ...rest
}: ButtonProps) {
  const cls = [
    styles.base,
    styles[variant],
    fullWidth && styles.fullWidth,
    className,
  ]
    .filter(Boolean)
    .join(' ');

  const externalProps = external
    ? { target: '_blank', rel: 'noopener noreferrer' }
    : {};

  return (
    <a className={cls} {...externalProps} {...rest}>
      {children}
    </a>
  );
}
```
