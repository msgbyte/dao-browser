> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task in the primary checkout.

**Goal:** Upgrade Dao from Chromium 149.0.7827.201 through each intervening milestone to 154.0.8037.100, preserving existing Dao behavior.

**Architecture:** Keep `src/dao/`, `src/patches/`, configuration, and import rewrites canonical. At each milestone, sync the existing Chromium checkout, adapt the overlay, and confirm compilation before advancing. Preserve existing build output and user profiles.

**Tech Stack:** Chromium C++, Objective-C++, GN, Lit/TypeScript, and the existing Dao CLI.

**Spec:** The user's sequential M149 to M154 upgrade request; repository `AGENTS.md`, `docs/chromium-upgrade-guide.md`, and `docs/feature-checklist.md`.
