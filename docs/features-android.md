# Dao Browser Android Feature Inventory

> This document catalogs features owned by the standalone Android GeckoView
> application under `android/`. Desktop Chromium features are documented in
> [`features.md`](features.md).

## 1. Android Foundation

- **Standalone GeckoView application** (`android/`) — A Kotlin/Compose Android application that consumes Mozilla Android Components and GeckoView as pinned Maven dependencies and builds locally on macOS.
- **English-first system localization** — The unqualified Android catalog is canonical English, Simplified Chinese is a complete qualified resource, and standard Android resource resolution follows the system locale with English fallback. Locale-sensitive history and new-tab formatting use the selected resource pattern and active locale. The root `i18n.sh` command dispatches independent desktop and Android GPT-5.5 translators; Android generation validates complete key parity, format placeholders, inline markup, and atomic XML output without sharing runtime resource files with desktop Chromium.
- **Android Components tab store** — A ViewModel-owned `BrowserStore`, backed by `EngineMiddleware`, is the single source of truth for Gecko tabs, selection, navigation actions, and engine-session lifecycle.
- **Mobile tab switcher** — Compact Chrome-style count frames expose the live tab count from the idle new-tab search field and browsing address bar, and open a full-screen two-column grid. The frame disappears while the new-tab search editor is expanded so editing actions remain uncluttered. Cards support tap-to-switch, an explicit close action, swipe-right-to-close, and new-tab creation; closing the final tab immediately creates a replacement with the same privacy mode.
- **Real tab thumbnails** — Opening the tab grid captures the visible page, including the Compose-based new-tab page and Gecko-rendered web content, into a bounded thumbnail before the grid reads it. Regular thumbnails are cached atomically on disk, while private thumbnails remain memory-only and are removed with their tabs.
- **Regular-session restore** — Mozilla Android Components `SessionStorage` restores regular tab order, selection, URLs, Gecko navigation history, and the active page's scroll position after process death. Before the activity leaves the foreground, Dao asks each regular Gecko session to flush its latest state so the background snapshot contains the current viewport. Private tabs are intentionally excluded; default-private startup clears any regular snapshot before creating a private blank tab.
- **Address-or-search navigation** — Localized browser chrome resolves HTTP(S), domain, and search input and sends navigation through the Android Components engine session.
- **System web-link handling** — Android registers Dao as an HTTP(S) browser candidate and routes both cold-start and warm `ACTION_VIEW` intents into Gecko. An external link reuses a selected blank tab or opens beside an occupied tab with the same privacy mode, while non-web intents and malformed hostless URLs are ignored.
- **Safe edge-to-edge browser chrome** — The Compose root stays inside safe drawing insets for system bars and display cutouts while the activity uses consistent edge-to-edge behavior.
- **Hierarchical destination motion** — Utility and nested pages use short directional slide-and-fade transitions, the tab grid uses subtle fade-and-scale motion, and changes among the browser, new-tab page, and address editor remain immediate.
- **Shared Dao brand identity** — The Android launcher, new-tab page, and About page reuse the canonical borderless ink-circle artwork rather than the macOS-specific framed application icon. Android resource qualifiers select the existing dark artwork from `branding/dao_logo.png` on light surfaces and the existing white artwork from `branding/product_logo_dark.svg` on dark surfaces without runtime tinting. The adaptive launcher foreground and legacy mipmap fallbacks remain untinted and keep the mark inside OEM-safe insets so vendor launchers, installers, masks, and scaling do not crop or overfill it.
- **Nova new-tab experience** — A token-driven Compose start page provides animated search activation, persisted recent visits and bookmark suggestions, highlighted matches, and a CameraX/ZXing QR scanner that opens decoded content through the normal navigation policy. A localized top-right Settings action opens the existing preference screen and hides while search editing is expanded. The idle search pill is a non-editable surface; activation composes the real input, focuses it, and opens the software keyboard.
- **Minimal browsing chrome** — Real GeckoView content is paired with a single top address bar and a right-side drawer containing back, forward, reload, share, Home, QR scanning, browser-library destinations, and a direct light/dark theme toggle. Reload closes the drawer before refreshing. Android Back and a left-edge right swipe navigate the current Gecko page backward when history is available. Home reuses the selected tab, preserves its count, and restores the previous page on Back. The address security icon opens a localized bottom sheet backed only by the selected Gecko session's live security state, including available certificate identity, validity, serial number, and SHA-256 fingerprint fields. Unavailable navigation actions use disabled semantics and faint styling, drawer-button ripples stay clipped to their rounded shapes, real Gecko loading progress animates as a clipped address-background fill without moving page content, and top-edge pull-to-refresh reloads without intercepting ordinary mid-page scrolling.
- **Persistent browser library** — SQLite-backed history, bookmarks, reading-list entries, and bookmark folders drive both the new-tab suggestions and the library screens. Visits are recorded after real Gecko loads complete, and the drawer's current-page action switches between an outlined and filled star as bookmark state changes.
- **System downloads** — Gecko external-resource callbacks enqueue HTTP(S) downloads through Android `DownloadManager`, persist Dao-owned task metadata, expose real status and progress, and support cancel, retry, delete, and open actions.
- **Persistent browser preferences** — DataStore saves theme, Gecko page font scale, the selected Google, Baidu, Bing, or DuckDuckGo search engine, recommended tracking protection, and default-private startup behavior. The browsing drawer toggles the persisted light or dark theme directly, while runtime-safe Gecko settings update the active engine/session immediately.
- **Dedicated About and bundled notices** — Settings opens a dedicated About screen that reads the installed app version and the build-owned Mozilla Components engine version. Its Open Source Licenses route lists the APK-bundled uBlock Origin and KISS Translator notices and opens their legal text from local assets without a network request. Back returns Licenses to About to Settings, then restores the browser or new-tab destination that originally opened Settings.
- **Opt-in USB remote debugging** — An always-visible developer-tools setting enables GeckoView's Firefox DevTools channel only after a first-use security acknowledgement. The persisted switch applies before the first browser session and updates the process-wide runtime immediately; an in-app guide opens Android developer settings and copies `about:debugging`. Android ADB authorization remains mandatory, and Dao exposes no network listener.
- **Installed extension management** — The extensions screen lists only WebExtensions reported by Gecko, displays their real metadata and enabled state, and forwards toggles to the engine. Its Store is a native Compose catalog: a blank search shows AMO recommendations, submitted searches replace the catalog, and later pages append without duplicate extension IDs. Catalog requests ask AMO for Android extensions compatible with the running Gecko major version, then accept only public HTTPS `.xpi` results. Opening the Store, reviewing an add-on, and installing it do not replace or reselect the active `BrowserStore` tab. Store installs pass AMO's direct package URL to Gecko with `RTAMO`; before Gecko completes an install, Dao shows its requested browser permissions, site access, and data-collection permissions and requires explicit approval. The local `.xpi` picker flow remains available and stages a selected package for Gecko's `FROM_FILE` path until that install finishes or fails. Release GeckoView still enforces Mozilla signatures, compatibility, and blocklists for both paths; unsigned, incompatible, corrupt, or blocklisted packages are rejected. Catalog fetch failures show a Retry action. Remote install failures reuse the localized extension-install status; after the user dismisses that result with Done, the add-on's Install action becomes available again. Extensions with a Gecko browser action expose an Open control; popup sessions render in a full-screen extension surface while `BrowserStore` keeps the originating web tab selected, preserving the extension's active-page context. User-installed extensions can be disabled or uninstalled, while APK-bundled extensions cannot be removed from the UI.

## 2. Built-in Ad Blocking

- **uBlock Origin 1.72.2** — The APK includes a GeckoView compatibility variant of the Firefox WebExtension and requests its installation through the process-wide GeckoEngine before the first regular session is created. The bundled manifest removes only the unsupported desktop `menus` permission and `commands` entry; blocking code and filter assets remain unchanged.
- **Offline default enablement** — Blocking is enabled by default, requires no first-run download, and updates with the APK.
- **Failure isolation** — Installation failure is logged without blocking browser startup.
- **Packaging integrity** — Build verification pins the extension ID, version, manifest version, provenance, required files, GeckoView manifest compatibility, and `_locales` packaging.

## 3. Built-in Translation

- **KISS Translator 2.0.29** — The APK includes the unmodified Mozilla-signed Firefox package under GPL-3.0-only and installs it as a built-in Gecko extension. A Gecko profile that does not yet contain KISS starts with the extension disabled; later launches preserve Gecko's existing user-selected enabled state. Its upstream UI provides paragraph-by-paragraph bilingual page translation, input and selected-text translation, and subtitle translation without a Dao-owned translation service.
- **Service and migration boundary** — Page content is sent to the translation service selected inside KISS Translator, subject to that service's privacy policy. After KISS installs successfully, Dao removes the previously bundled TWP extension from upgraded profiles while preserving other extensions.
- **Packaging integrity and failure isolation** — The pre-build audit pins the stable Gecko ID, version, SHA-256, source, GPL-3.0-only notice and license, popup/options UI, locale data, and Mozilla signature metadata. Installation or legacy cleanup failure is logged independently and does not block startup.

## Current Status

- **Target**: API 26+ application, compiled and targeted against SDK 36.
- **Engine**: Mozilla Android Components and GeckoView 153.0.2. The About page identifies the browser engine as `Gecko 153.0.2`, with the version sourced from the Gradle catalog.
- **Verification**: Local build, unit, lint, APK-content, and API 34 emulator checks are available.
- **Foundation gaps**: An in-session regular/private mode switch, password storage, sync, Agent, MCP, and a dedicated ad-blocking preference are not implemented.
