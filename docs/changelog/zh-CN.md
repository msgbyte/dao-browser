# 更新日志

## [desktop] 桌面版

### [Unreleased] 未发布

- GitHub 发布说明现在包含每条提交，未经过 Pull Request 的改动也会出现在更新记录中。
- 每次改动都维护中英文更新记录，桌面、Android 和 iOS 分别记录版本。
- 可通过现有翻译脚本生成其他语言的更新记录，内容未变的条目在版本归档后仍可复用译文。
- 桌面发版时，将待发布记录归入新版本；发版失败会恢复原记录。归档后的记录也不会再阻止 Windows 使用同一个发布 tag。
- 按 Git tag 补齐桌面和 Android 的历史更新记录，重新核对各版改动，补充功能细节并改写说明。

### [1.0.108] - 2026-09-22

- 标签可以在窗口之间拖动，也可以拖到桌面开成新窗口，页面状态和访问历史会一并保留。
- 拖动窗口里唯一的标签时，会直接移动整个窗口；按 Escape 可以取消拖动。
- 后台标签可以通过右键菜单移到新窗口；窗口只剩一个标签时，这项操作不可用。
- 在窗口之间移动固定标签时，不再把移动误判为关闭页面。
- 文件夹的改动会在窗口间同步，重启浏览器后也会保留标签原本所在的文件夹。
- 补充桌面、Android 和 iOS 的隐私政策草案。

### [1.0.107] - 2026-09-19

- 浏览器操作支持批量执行，减少来回调用。某一步失败后，后续步骤会停止。
- 浏览器自动化补充了填入内容、按键和等待操作，并加入执行检查。
- MCP 客户端数量达到上限时，可以清理空闲连接，为新客户端腾出位置。
- 后台页面加载时，不会再让当前页面的加载提示跟着闪烁。
- 关闭重复标签后，会显示实际关闭的数量；在离开页面提示中取消关闭的标签不会被算进去。
- MCP 使用记录较多时，会在固定高度内滚动，不再把设置页面越撑越长。

### [1.0.105] - 2026-09-12
