### [1.0.119] - 2026-10-24

- macOS 主窗口改为不透明背景，避免浏览器内容未绘制时直接透出桌面。
- 使用旧更新地址的 Windows 版本需要手动升级一次，才能继续接收自动更新。
- AI 现在可以在使用你登录状态的后台任务窗口里工作，不再占用你的标签页。侧边栏会列出每个任务及其进度：悬停可实时查看，展开可观看页面与操作步骤，也能随时接管、交还或停止。
- 后台 AI 任务在需要你处理时会暂停并提醒你，比如登录或回应网站的权限请求，交还后继续执行。
- 网站要求选择文件或设备，或弹出登录、安全密钥、证书提示时，后台 AI 任务也会交给你处理；网页里简单的确认弹窗它可以自己回应。
- AI 任务需要你处理时，Dao 还会发送系统通知，点击即可打开该任务。
- 后台 AI 任务下载的文件会直接保存到“下载”中按任务划分的文件夹，不再弹出询问。
- AI 任务完成后可以把结果页面移到侧边栏的“AI 结果”文件夹，并简短提示新增了哪些页面；重启 Dao 后，已完成的任务仍会保留在列表中。
- Dao Agent 第一次开始后台任务前会先询问你，你也可以在 AI 设置中让它不再询问。
- AI 任务可以在不使用你登录状态的干净窗口中工作。
- Claude Code、Codex 等本机 Agent 可以通过新的 `dao-browser` 命令使用 Dao，一次运行完整的多步浏览器脚本；打开 MCP 服务器后，Dao 会为这些 Agent 安装该命令和随 Dao 更新保持最新的技能说明，设置中也会显示哪些 Agent 已完成设置。
- 本机 Agent 可以只申请在后台任务窗口中工作，你也可以对信任的 Agent 设置始终允许；关闭 MCP 服务器即可收回这项授权。

### [1.0.111] - 2026-10-13

- Fast Checks 现在会安装官网依赖，下载页测试可在全新的 CI 环境中正常运行。
- 发布测试改用本地日历日期，更新日志检查在 UTC 的 CI 环境和开发者本地时区均可通过。
- Windows 构建参数测试使用独立的版本数据，正常升级发布版本不再导致 CI 失败。
- 可在 Agent 设置中为实验性 Jev 插件填写自定义模型 ID；留空时，Agent 和 MCP 浏览器任务继续使用 `jev-latest`。
- 桌面发布不再回下载完整安装包和增量包来校验上传，避免 R2 上传成功后，公开地址暂时返回旧的 404 响应导致发布中断。
- 发布检查请求未压缩的文件大小，并兼容缺少大小响应头的情况；网络请求失败时会显示具体地址和底层错误。
- 官网仅在 macOS 上自动开始下载；其他设备显示手动下载页面，可选择已配置的各平台安装包，避免自动下载不适用的文件。

- 使用已配置的 AI 模型将当前窗口中未分类标签页整理到文件夹，也可只分类指定标签页下方的页面，保留已有分组。
- AI 每次分类都会优先复用已有分类，并按需创建新分类；可在设置中新增、重命名或删除分类，删除分类不会关闭其中的标签页。
- AI 分类期间关闭标签页，不再丢弃其他标签页的分类结果；关闭分类范围之外的标签页也不会中断分类。
- 旧版文件夹数据含有重复标签页记录时，AI 分类也能正常保存，不再把未变化的数据误判为编辑冲突。
- 修复 AI 标签分类代码导致的 TypeScript 编译失败；没有分类任务时，缺少请求 ID 的取消事件会被安全忽略。
