# iOS icon sources

SVGs copied verbatim from [Lucide](https://github.com/lucide-icons/lucide/tree/a537cb6eb323b885f4c60baf3cec1a995982d167/icons), commit `a537cb6eb323b885f4c60baf3cec1a995982d167`. PDF image sets are vector exports with `currentColor` resolved to black; SwiftUI uses template tinting. Exported with svglib and ReportLab, neither is an app dependency.

Upstream renamed icons: `history` uses `rotate-ccw.svg`; `trash-2` uses `trash.svg`. The Dao logo and app icon come from `branding/dao_logo.png`.
